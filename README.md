## 🎯 Why Fortran?
- **Speed**: It's incredibly fast for heavy mathematical computations.
- **Legacy**: It powers the world's top supercomputers (weather models, astrophysics).
- **Quant Finance**: High-Frequency Trading (HFT) firms still use Fortran/C++ for execution engines due to their raw speed and memory management.
